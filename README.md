# GEODA
Juego idle: **rompe geodas, recoge gemas, mejora tu equipo y desciende** entre zonas.

- Un solo archivo, sin dependencias ni build: `geoda.html`
- Juega abriéndolo en el navegador (doble clic) — táctil, ratón y teclado
- Canvas 2D + CSS, guardado local en el navegador

*(proyecto independiente; nada que ver con Neon-Coast ni neon-rush)*
